# Quotes

## Purpose
Create quote proposals with statuses and convert downstream into invoicing/agreement workflows.

## Before You Start
- Active workspace and FY filter are correct.
- Client exists.

## Steps
1. Open Revenue > Quotes.
2. Create quote and fill title, status, valid until, notes.
3. Maintain line items in line items dialog.
4. Save quote.
5. Use row/bulk actions:
   - Send reminders
   - Compose email
   - Generate PDF
   - Edit/delete
6. Link quote during invoice/agreement creation where applicable.

## Expected Result
Quote appears in list with status and totals; related workflows can reference it.

## Common Mistakes
- Not updating quote status before reminder/send campaigns.
- Forgetting valid until date for expiring quotes.
