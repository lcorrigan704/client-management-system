# Revenue Adjustments

## Purpose
Create credit notes and refunds against invoices with transparent line-level controls.

## Before You Start
- Active workspace is correct.
- Target invoice exists and has creditable balance.

## Steps
1. Open Revenue > Adjustments.
2. Create credit note:
   - Select invoice
   - Select quantities/amounts by line
   - Add notes
3. Save credit note.
4. Create refund against a credit note as required.
5. Edit/delete credit notes and refunds through row actions.

## Expected Result
Adjustment totals and remaining values update correctly and are reflected in tax/profit summaries.

## Common Mistakes
- Crediting more than remaining balance.
- Creating refunds without confirming credit note availability.
