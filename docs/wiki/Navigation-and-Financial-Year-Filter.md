# Navigation and Financial Year Filter

## Purpose
Explain navigation structure and how the global FY filter affects data views.

## Before You Start
- You are logged in and viewing the main app shell.

## Steps
1. Use the sidebar groups:
   - Overview
   - Clients
   - Revenue
   - Agreements
   - Operations
2. Set the global FY filter from the sidebar (`All FYs` or specific year).
3. Navigate between pages and confirm filtered totals/lists update accordingly.

## Expected Result
Selected FY context is applied consistently across dashboard and operational pages where relevant.

## Common Mistakes
- Assuming the FY filter changes tenant/workspace scope.
- Expecting historical data when a narrow FY is selected.
