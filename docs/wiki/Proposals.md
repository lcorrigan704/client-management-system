# Proposals

## Purpose
Create and manage proposals with requirements, attachments, versioning, comments, reminders, and outbound docs.

## Before You Start
- Active workspace is correct.
- Client exists; quote link optional.

## Steps
1. Open Agreements > Proposals.
2. Create proposal with title, status, dates, and body fields.
3. Add requirement items.
4. Upload and attach supporting files.
5. Save proposal.
6. Use version history and field comments as needed.
7. Use reminders/compose/PDF actions.
8. Edit/delete through row actions or bulk actions.

## Expected Result
Proposal data, attachments, and collaboration history are persisted and reusable in communications.

## Common Mistakes
- Uploading files before checking workspace context.
- Sending reminders when proposal status is not ready.
