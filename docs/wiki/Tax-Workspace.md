# Tax Workspace

## Purpose
Review VAT and direct tax planning estimates for the active workspace.

## Before You Start
- Active workspace is correct.
- FY filter in sidebar is set to desired reporting year.

## Steps
1. Open Operations > Tax.
2. Review tabs:
   - VAT summary (visible when VAT registered)
   - Direct tax estimate
   - Filing pack
3. Open Configure tax settings dialog for policy/identity defaults.
4. Export filing pack as CSV/PDF as needed.

## Expected Result
Tax summaries align to active workspace + selected FY and provide planning guidance.

## Common Mistakes
- Treating estimates as filed returns.
- Expecting VAT tab when VAT is not registered.
