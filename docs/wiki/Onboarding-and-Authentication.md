# Onboarding and Authentication

## Purpose
Document first-run setup and login behavior.

## Before You Start
- No users in system triggers setup wizard.
- Owner credentials are required for first setup.

## Steps
1. Complete setup wizard sections:
   - Owner account
   - Company profile
   - Financial dates
   - Bank details (optional)
   - SMTP (optional)
2. Submit wizard to create owner and initial workspace.
3. Log in with owner credentials for normal usage.
4. Use `Users` (owner-only) to add additional users.

## Expected Result
Owner account is created, workspace is available, and normal auth status is active.

## Common Mistakes
- Weak password that does not satisfy policy.
- Skipping SMTP then expecting reminder/send actions to work.
