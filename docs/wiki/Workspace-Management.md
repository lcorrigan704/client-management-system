# Workspace Management

## Purpose
Manage multiple businesses/consultancies under one account with strict data isolation.

## Before You Start
- User must be workspace member.
- Owner/admin permissions are required for create/rename/member management operations.

## Steps
1. Open workspace switcher in sidebar header.
2. Switch active workspace.
3. Optional: create workspace, rename active workspace, set default workspace.
4. Manage members/roles for a workspace (owner/admin paths).
5. Verify data isolation by checking clients/revenue/operations after switching.

## Expected Result
All entity data and settings are scoped to active workspace; switching changes context safely.

## Common Mistakes
- Creating records in the wrong active workspace.
- Expecting tenant backup/restore behavior from workspace-scoped actions.
