# Settings

## Purpose
Configure workspace operational defaults (company profile, prefixes, FY dates, compliance dates, bank details, SMTP).

## Before You Start
- Owner/admin role in active workspace.

## Steps
1. Open Settings from account menu.
2. Update sections as needed:
   - Company profile
   - Document prefixes
   - Bank details
   - Financial year/compliance dates
   - SMTP configuration
3. Save section changes.
4. Test SMTP connection after SMTP updates.

## Expected Result
New records and communications use updated workspace-specific settings.

## Common Mistakes
- Editing settings in wrong workspace.
- Skipping SMTP test after credential changes.
