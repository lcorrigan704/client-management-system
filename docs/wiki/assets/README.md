# Wiki Assets

Store targeted screenshots/GIFs used by wiki pages.

Naming convention:
- `workspace-switcher.png`
- `emails-compose-groups.png`
- `tax-config-dialog.png`
- `danger-zone-delete-workspace.png`
- `adjustments-line-entry.png`

Guidelines:
- Prefer PNG for static UI screenshots.
- Crop to the relevant UI area only.
- Avoid including personal/client-identifying data.
