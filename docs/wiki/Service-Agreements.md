# Service Agreements

## Purpose
Manage service agreements with version history and threaded comments/reactions.

## Before You Start
- Active workspace is correct.
- Client exists; quote link optional.

## Steps
1. Open Agreements > Agreements.
2. Create agreement with structured fields and SLA items.
3. Save agreement.
4. Use version history dialog to review/restore versions.
5. Add comments/reactions on tracked fields.
6. Use compose/PDF/export actions as needed.
7. Edit/delete agreement when required.

## Expected Result
Agreement lifecycle is tracked with recoverable versions and collaboration metadata.

## Common Mistakes
- Restoring a version without reviewing latest edits.
- Missing required signatory metadata for final handoff.
